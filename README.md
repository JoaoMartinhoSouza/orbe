## Orbe: um programa gerenciador de TCCs

Este repositório contém o código do Orbe, um sistema de gerenciamento de TCCs que eu escrevi em 2025 sob a orientação 
do [@dalton-reis](https://github.com/dalton-reis). O Orbe foi projetado para ajudar os professores e alunos do nosso departamento a lidar 
com a comunicação e a troca de documentos exigidas pela disciplina TCC I.

Observe que este é o código original do programa, tal como foi apresentado por mim como o meu TCC, e pode ter sofrido alterações 
durante a fase de manutenção.

### Como contribuir

Se você é um aluno ou professor da FURB e quiser sugerir alguma alteração no código, sinta-se à vontade para criar 
um ticket aqui no GitHub ou, se quiser fazê-la você mesmo, abrir uma solicitação de mesclagem.
